# GPT-bottipalvelin

Tämä on yksinkertainen Node.js-palvelin, joka yhdistää OpenAI GPT-4.1 miniin ja vastaa POST-pyyntöihin reitissä `/kysy`.

## Käynnistys

1. Luo `.env`-tiedosto ja lisää sinne:
   OPENAI_API_KEY=your_openai_api_key_here

2. Asenna riippuvuudet:
   npm install

3. Käynnistä palvelin:
   node server.js
